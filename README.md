# Day Skipper Recall

Offline-capable study app (installable web app) for RYA Day Skipper theory: lessons, spaced-repetition cards, glossary.

- Progress is stored on the device (localStorage). Use **Back up** / **Restore** at the bottom of the Today tab.
- Works offline after the first load (service worker caches everything).
- Content: 48 lessons, 583 cards, 84 glossary terms.
